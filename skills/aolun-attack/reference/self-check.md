# 质量自检清单（aolun-attack 引用）

> 供 `aolun-attack/SKILL.md` 使用。**发布前**逐条过一遍；有任何一条不满足，先修再发。这是证据纪律与核心方法论的最后一道闸，不得跳过。

**【第一层：辩证诊断】**
- [ ] 主要矛盾已定位，不是表面现象（至少从3条张力中选出）
- [ ] 矛盾类型已确认，主攻路线已选定
- [ ] 主要方面已识别，攻击对准支配地位的那个方面
- [ ] 转化条件已找到，"立"从内部矛盾中生长而非外加
- [ ] 对抗性已判断，反讽力度与之匹配

**【第二层：攻击执行】**
- [ ] 每个主要指控有具体依据（来自解剖/扫描结论）
- [ ] 征引选择与矛盾类型匹配
- [ ] 解构路线对应主攻路线，不是套模板
- [ ] 解构终点已到达（读者能看到转化条件）
- [ ] 反讽在论证之后，落点在主要方面
- [ ] 没有用气势代替论证

**【第三层：实践检验】**
- [ ] "立"有实践来源，有边界条件，有可操作性
- [ ] 能回答：读者第一个具体动作是什么
- [ ] 三种对手反击已模拟，伏笔已预埋
- [ ] 没有人身攻击，批评的是论断和行为

**【认识的螺旋：发布决策】**
- [ ] 三条发布标准满足（主要矛盾定位 ✓、核心弱点有据 ✓、立可操作 ✓）
- [ ] 对方优点（如果真有）被公平提及
- [ ] 字数与信息密度匹配，没有冗余铺垫
